OUR THREE TYPES OF HTML LIST

1. UNORDERED LIST (ul)

Used when the chronological sequence of items does not matter. Items are marked with BULLET POINTS by default.

Parent container uses the (ul) tag.

Each individual item uses the list item or (li) tag.

Bullet styles can be changed with CSS list-style-type (ex. square or circle).

Example: Groceries

  • Milk
  • Egg
  • Bread
  • Sugar
  • Coffee supplies
    • Coffee beans
    • Creamer
    • Sugar

2. ORDERED LIST (ol)

Ordered lists are used when the sequence of the items is important. Items are marked with NUMBERS by default.

Parent container uses the (ol) tag.

Each individual item uses the (li) tag.

Customize markers using the type attribute. (ex. type="A" for letters, type="I" for Roman numerals).

Reverse numbering order using the reversed attribute.

Change the start value using the start attribute.

Example: Morning Routine

  1. Prayer
  2. Exercise
  3. Walking/running
  4. Eat breakfast
  5. Bath
  6. Work

3. DESCRIPTION LIST (dl)

Used for key-value, glossaries, or terms and definitions. They do not use standard bullet points or sequential numbers.

Parent container uses the (dl) tag.

The term is wrapped in a (dt) tag.

The explanation is wrapped in a (dd) tag.

PRAYER
A solemn request for help or expression of thanks addressed to God or an object of worship.
EXERCISE
Activity requiring physical effort, carried out to sustain or improve health and fitness.
WALKING
Move at a regular pace by lifting and setting down each other foot in turn.
BREAKFAST
A meal eaten in the morning, the first of the day.
BATH
An act or process of immersing and washing one's body in a large container of water.
WORK
A purposeful mental or physical effort directed toward achieving a result.

OUR HYPERTEXT MARKUP LANGUAGE (HTML) TABLE

An HTML TABLE is created using the (table) tag, which arranges structured data into rows and columns.

CORE HTML TABLE TAGS:

  1. table: Enclose the entire table data structure.
  2. tr: Defines a single horizontal TABLE ROW.
  3. th: Sets a TABLE HEADER cell.
  4. td: Specifies a standard TABLE DATA cell.

SEMANTIC STRUCTURAL ELEMENTS

For larger or complex datasets, use semantic tags to group our structural sections:

  1. caption: Places a descriptive title directly above the table.
  2. thead: Wraps the master header rows of our dataset.
  3. tbody: Groups the primary body content containing data rows.
  4. tfoot: Encloses summary or total rows at the bottom.

SPANNING LAYOUT ATTRIBUTES

  1. colspan: Stretches a data cell horizontally across multiple columns.
  2. rowspan: Extends a single cell vertically down across multiple rows.

HYPERTEXT MARKUP LANGUAGE (HTML) FORM

HTML FORMS are used to collect user inputs such as login credentials, search queries, or contact details and send them for processing. They are defined using the container (form) element, which holds various interactive controls like TEXT BOXES, RADIO BUTTONS, and SUBMIT BUTTONS.

CORE FORM ATTRIBUTES:

  1. ACTION: The URL endpoint where the form data will be processed upon submission.
  2. METHOD: The HTTP method used to send data.
  • GET: Appends data to URL (visible, best for un-sensitive search features).
  • POST: Sends data in the request body (hidden, best for sensitive login credentials).
  1. NAME: The key identifier assigned to each input. The server reads form data in name=value pairs.

COMMON FORM ELEMENTS

  1. LABEL: Provides text context for form inputs. Its for attribute must match the input's id to ensure web accessibility.
  2. INPUT: The primary self-closing entry element. Its rendering changes drastically depending on the type attribute:
    • type="text": Standard text box.
    • type="password": Obscures typed characters.
    • type="radio": Selects one option from a grouped set.
    • type="checkbox": Selects multiple stand-alone options.
  3. TEXTAREA: Creates a larger, multi-line field ideal for messages or comments.
  4. SELECT & OPTION: Builds a dropdown selection menu.

BUILT IN VALIDATION ATTRIBUTES:

  1. REQUIRED: Blocks form submission if the input field is left empty.
  2. PLACEHOLDER: Displays a temporary hint text inside the input box.
  3. MINLENGTH/MAXLENGTH: Imposes exact text character counts.
